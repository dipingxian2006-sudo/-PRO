## 一、原版已经能做什么

原版狗头军师已是一套“数据解析 → 人物画像 → 心理模型 → 策略建议”的关系分析工作流，包括：

- 解析用户提供的聊天记录，描述消息数量、发起、回应等可观察行为。
- 分析双方沟通风格、需求、投入模式及容易冲突的地方。
- 使用依恋、爱情三角、Gottman、荣格与 MBTI 等模型作为解释框架。
- 运行互动波段、VOL、差评/好评、异动四大方法。
- 输出完整报告、片段快照、当日聚焦报告和即时话术。
- 提供全面复盘、周期跟踪和下一阶段行动建议。
- 要求证据核查，不自动采集微信数据，不自动发送消息。

因此，本版不能把“四大方法”“第一次支持日报”“第一次有总结”作为全新功能宣传。准确的说法是：**在既有分析基础上，增加双轨输出契约，强化决策、跟踪和解释边界。**

## 三、重点新增：两种分析方法分别给结果

原版的“心理模型层 + 策略决策层”主要回答为什么和怎么办。V2 的“双轨”进一步要求：同一份证据，从两个不同任务角度分别形成可检查的结论。

### 结果 A｜关系优势策略

围绕用户的利益、投入与选择权，分析：

1. 当前有哪些有利条件、失衡和消耗。
2. 主动性、现实投入、回应与修复分别由谁承担。
3. 用户需要维护什么边界，哪些单向投入可以减少。
4. 下一步怎么做，观察什么，何时停止。

“优势”指用户更清楚自己的选择和可承担范围，保留协商、拒绝与退出的权利，不以控制对方为目标。

### 结果 B｜客观关系与双向沟通

围绕共同事实和双方立场，分析：

1. 原话、行为和约定能够确认什么。
2. 双方可能有哪些合理关切。
3. 哪些心理动机未知，有哪些情境性替代解释。
4. 如何表达事实、请求和边界，如何保留双方选择空间。

两轨共享事实，分别回答问题。不能为了突出用户优势而改写对方原话，也不能以“客观”为由淡化失约、投入失衡或用户的合理利益。

**变化示例：**

对方说“这周比较忙，下周再看”，且没有给出具体时间。

- **A 轨**：目前没有落实安排，不需要连续追问或继续加码；后续观察是否主动给出可执行时间。
- **B 轨**：只能确认对方表示忙，并暂缓安排；真实忙碌、尚未确定日程、意愿有限等解释仍需区分。
- **综合行动**：依据上下文轻接收束，保留后续空间；不把这句话单独解释成好感或拒绝的证明。

以上为虚构示例，用于说明输出差异。

## 四、逐句分析升级在哪里

原版已经要求先逐句扫描，再聚合总结。V2 增加的是更明确的覆盖与追溯要求：

- 每条范围内消息都有 A 轨和 B 轨分析。
- 同一消息包含多个独立句意时，可以拆分分析单元，但保留原消息映射和顺序。
- 没有关系信号的句子也保留，不为凑分析而编造隐藏含义。
- QUICK 对贴出的句子保留双轨简版；快照与聚焦报告逐句列出；完整报告提供完整附录。
- 长记录分块处理并交代覆盖数量，不能只挑“有戏”的句子。
- 日报、总结和关键建议都应能够回指原始单元。

这让用户能检查“结论从哪句话来”，也能发现分析是否忽略了反例或普通日常内容。

## 五、聊天参谋新增两套完整方案

V2 不只给两段分析，还在聊天策略任务中分别提供：

| 输出内容 | 方案一：关系优势型聊天参谋 | 方案二：客观共情型聊天参谋 |
| --- | --- | --- |
| 判断重点 | 用户投入、边界、选择空间 | 共同事实、双方立场、沟通障碍 |
| 聊天策略 | 是否继续投入，如何减少无效追加 | 如何澄清误解、回应内容和明确感受 |
| 互动节奏 | 根据真实反馈继续、收束或停止 | 根据接收条件和沟通目的安排表达 |
| 推荐话术 | 行动权限允许时提供 | 行动权限允许时提供 |
| 后续分支 | 若出现某种反馈，再采取相应行动 | 若出现某种理解或分歧，再采取相应行动 |
| 停止条件 | 持续失衡、明确拒绝或越界等 | 明确不适、无法接收、无需重复解释等 |

最后说明更推荐哪套方案，或如何融合。条件分支写成“若出现 X，则 Y”，不预测对方一定会回复。

### A–E 行动决策

| 行动代码 | 含义 | 话术规则 |
| --- | --- | --- |
| A 继续 | 有合适内容和继续交流的入口 | 默认提供一条自然回复 |
| B 轻接收束 | 接住当前内容，结束这一轮 | 提供简短承接或收尾 |
| C 不回复 | 当前无需追加消息 | 不生成立即发送话术 |
| D 另起话题 | 有适合另开话题的真实内容 | 结合语境给出自然开口 |
| E 修复降压 | 优先处理不适、拒绝或沟通压力 | 只提供尊重边界或修复表达 |

这里的“结果 A”是分析轨道，“A 继续”是行动代码，两者不是同一概念。

## 六、日报新增和强化的具体内容

原版日报主要还原当天对话、列出四种方法、批改用户动作并给出待观察项。V2 在此基础上补充：

1. **逐句双轨时间线**：每句同时检查用户投入与双方沟通事实。
2. **两个独立结果块**：当天有利与失衡之处、双方关切和未知项分别呈现。
3. **当前策略执行记录**：对于用户明确采用的策略，检查是否自然轻触、对方是否延展、用户是否及时收束。
4. **策略效果核验**：没有新消息就记录没有新消息，不自动解释为对方好奇、失落或策略生效。
5. **更明确的数据边界**：没有昨日材料就写无法比较，不强制给出升、平、降。
6. **行动与停止条件**：是否继续交流先于话术生成，明确拒绝和不适优先处理。

“轻触—响应—收束”和“1–2 周观察窗”是包内明确写入的近期策略记录，使用时应核对用户当前目标和适用范围，不应宣传为适用于所有关系的通用疗程。

## 七、阶段总结新增和强化的具体内容

阶段总结保留原版全面复盘和周期跟踪，进一步检查：

- **策略是否真的执行**：实际发了什么、何时停止、是否出现连续追加或反复解释。
- **对方是否出现可观察反馈**：主动开启、追问、回访旧话题、给出安排、兑现约定。
- **双方是否都有现实投入**：把聊天热度与可落实的行动分开。
- **原解释是否需要修正**：新增材料支持了什么，推翻了什么，仍有哪些替代解释。
- **调整是否有依据**：继续、维持、减少投入或停止，分别对应哪些事实。
- **观察是否应提前结束**：不为凑满周期而忽略拒绝、不适或持续缺乏互惠。

总结不能只写“比上周好”，需要交代比较窗口、证据和缺口。跨会话保存与长期召回需明确授权及实际环境支持。

## 八、四大技能保留了什么，又校准了什么

四大技能仍属于同一个技能包内的四种分析方法，不是四个独立插件。

| 方法 | 原有能力 | V2 强调的校准 |
| --- | --- | --- |
| 互动波段 | 逐句标签、转折和触发句，辅助定位互动变化 | 标签是启发式候选；观察互动，不把数值当成真实心态测量 |
| VOL 事件窗口 | 比较事件前、冲击时和恢复阶段的表现 | 自动事件需核实；没有恢复数据不外推；前后关联不自动视为因果 |
| 正负表达 | 筛查批评、要求、肯定和表扬等表达 | 回到上下文检查玩笑、反讽、引用和漏检；不能用词典命中直接宣判关系 |
| 异动与长期变化 | 比较不同窗口的行为和话题维度 | 单日不推长期趋势；时间不可靠停用时间判断；变化不直接等于人格变化 |

四种方法用于互相检查解释是否一致，但共享同一语料的一致性不是独立验证。本版的主要提升在解释规则与输出结构，不能仅凭这些文档宣称算法准确率提高。

## 九、新增“人性与社会”分析内容

这里的“人性”指可讨论的心理与互动机制，不是对某类人作绝对判断。V2 增加两个专门参考方向：社会心理学证据迁移，以及沟通框架、群体影响与反馈循环。

### 1. 人格之外，也看情境

回复变少、退缩、情绪起伏，可能涉及个人意愿，也可能涉及工作、疲惫、家庭或互动压力。重要解释至少检查情境性替代解释；资料不足时不强行区分“性格如此”和“当时如此”。

### 2. 说法、选择和兑现分开记账

说重视、愿意安排时间、真正按约定出现，是不同层次的证据。表达不能替代后续兑现，一次顺从也不能替代持续意愿。

### 3. 互惠与隐性债务

检查礼物、照顾和让步是否被变成“你必须回报”的压力。用户可以维护自己的资源和期待，也需要把希望的回应说清楚，而非用付出兑换默认义务。

### 4. 承诺一致性与沉没成本

过去答应过，不等于现在不能改变主意；已经付出很多，也不等于必须继续。分析转向当前收益、自由选择与可承担成本，避免用既有投入证明关系一定值得。

### 5. 社会影响与群体压力

检查朋友、家人、身份权威、公开承诺和平台叙事是否压缩双方选择空间。公开顺从与私下意愿分别核对，重大决定在低压力条件下重新确认。

### 6. 确认偏差与自我合理化

对“她在试探”“他怕失去”等解释，同时找支持材料和反例。用户的期待与分析者的初始判断都可能影响选材，因此需要允许结论被修正。

### 7. 信息负荷与接收方视角

高情绪和冲突时，一条消息围绕一个主要目的展开；检查必要背景、精力与词义是否一致。精简结构，但保留会影响决定的重要事实和责任。

### 8. 互动循环与反馈延迟

按“触发 → 行动 → 回应 → 延迟 → 解释 → 补偿 → 下一轮”还原过程。追问—退缩、过度解释—回应减少等模式，可能由双方反应共同形成，不直接证明谁在故意操控。

在反馈尚未出现时，优先小幅、诚实、可逆地调整一个变量，避免连续加码后又突然大幅撤退。

这些参考吸收了包内列明的社会心理、传播与复杂系统资料，但不把教材概念、历史群体论或工程隐喻直接当成个人心理事实，也不将影响机制改写成顺从技巧。

## 十、新增分歧沟通四步流程

**表达立场 → 确认分歧 → 尊重对方 → 停止重复解释。**

1. 用事实、自己的考虑和可承担范围讲清立场。
2. 指出双方具体在哪里不同，不把讨论变成谁必须认错。
3. 保留双方选择权；理解与尊重不等于必须同意或让步。
4. 立场清楚后停止连发、自证和反复说服。

共同承诺、财务、安排和安全事项仍需处理事实、责任和选项。“停止重复解释”不能变成逃避共同责任。

## 十一、关系推进规则的强化

V2 将推进整理为“自然投入 → 观察反馈 → 判断互惠 → 推进一步、维持或停止”：

- 热聊和主动分享可以提供提出一次邀请的入口，不能直接证明对方有空或愿意见面。
- 邀请具体、轻量、可拒绝，拒绝后不追约。
- 自我披露逐步进行，保留独立生活；留白不用于制造焦虑。
- 身体接触单独检查同意，不从玩笑、靠近或其他动作推定。
- 见面后综合看主动延展、回应质量、现实投入、邀约兑现和边界反馈。
- 确认关系依据双向意愿、可靠性、核心条件和分歧处理，不用固定天数替代证据。
