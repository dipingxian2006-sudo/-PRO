# V2 授权记忆路由

历史材料用于补足明确约定和重复模式，不用于把一次推测固化成人物结论。只读取用户当前提供或明确授权的资料。

## 读取顺序

按当前问题选择最小范围：

1. 当前对话中可核对的原文和草稿状态。
2. 用户授权的最近 1–3 天日报或记录，优先其中已验证的事件。
3. 与当前议题直接相关的旧约定、旧分歧和边界。
4. 长期偏好或人物观察，仅在用户已同意保存且当前问题确实需要时读取。

没有授权资料时写“不知道”，不从昵称、MBTI、旧案例或常识补齐。检索不到资料也不能证明某件事从未发生。

## 授权边界

- “分析这份文件”只授权本次读取，不等于同意永久保存。
- 跨会话保存或更新人物观察前，需要用户明确同意保存对象、内容和用途。
- 用户可限定日期、对象和材料类型；范围外内容不读取。
- 原始聊天、长摘要、截图和完整报告不默认进入长期记忆。
- 可保存的最小事件记录应包含日期、简短事实摘要、证据定位和来源；推测必须标为假设。
- 用户撤回授权后停止后续写入；删除或撤销操作须按实际存储系统的能力执行，不能口头声称已删除。

## 召回输出

引用历史时注明日期、来源和与当前问题的相关性。若历史材料与当前原话冲突，以当前可核对事实为主，并明确冲突，而不是静默挑选更符合既有画像的一份。

第三方记忆项目和语义检索服务只能作为可选实现参考。未安装、未授权或无法核实运行边界时，不调用，也不声称已经检索全部历史。
