# 心理模型层

三个模型解决三件不同的事，不要互相替代：

| 模型 | 回答的问题 |
|---|---|
| 依恋模型 | 双方在压力/距离变化时的**行为模式**是什么，会不会形成追逃循环 |
| Sternberg 三角 | 这段关系的**互动表现**在三个维度上各有多强，短板在哪 |
| Gottman | 日常沟通的**质量与损耗**如何，有没有在积累不可逆的伤害 |

**总纲：这三个是组织互动证据的启发式框架。** 性格或依恋判断只能写成当前材料中的低确定性模式，不能诊断“回避型人格”、高神经质或固定类型。每项判断都要给证据、情境性替代解释和推翻条件；详细的社会心理学迁移限制见 [社会心理学证据迁移](social-psychology-evidence.md)。

需要区分的是**强度**：「呈现 X 倾向」是描述，「就是 X 的人」是贴标签。前者有证据支撑，后者通常没有。

## 一、依恋模型（Bartholomew 四象限）

两个轴：**对自我的焦虑（是否被抛弃）** × **对他人的回避（是否依赖他人）**。

| | 低回避 | 高回避 |
|---|---|---|
| **低焦虑** | **安全型** | **疏离型（回避）** |
| **高焦虑** | **痴迷型（焦虑）** | **恐惧-回避型** |

### 候选行为模式

| 候选模式 | 可能出现的可观测组合 |
|---|---|
| 安全型 | 发起与回应都较高且对称；冲突后能回到正常节奏；`response_rate` 高且稳定 |
| 痴迷型（焦虑） | `initiated_sessions` 明显高；`question_ratio` 高（反复求证）；`max_streak` 高；对方延迟变长时自己的发送频率**上升** |
| 疏离型（回避） | `char_avg` 低；`low_effort_ratio` 高；冲突/被追问后延迟显著拉长；很少开启，但接住率不一定低 |
| 恐惧-回避型 | 忽冷忽热：延迟方差极大、投入量波动大（某几天密集，之后突然沉寂） |

### 判断规则

- 至少两类独立证据、跨多个可比较情境一致时，才给出低确定性的倾向判断；否则写“待验证”。共享同一段语料的多个指标不算独立验证。
- 标注**触发条件**；若模式只在被追问计划、冲突或工作压力时出现，优先写成情境反应，不上升为稳定类型。
- 依恋类型会随对象和阶段变化，不要当成固定人格。

### 追逃循环（最重要的一条）

识别方法：把时间轴分段，看**一方的延迟变长后，另一方的发送频率是上升还是下降**。

```
A 延迟 ↑ → B 发送频率 ↑ → A 延迟进一步 ↑ → …   ← 追逃循环已形成
A 延迟 ↑ → B 发送频率 →（不变）                  ← 未形成，只是单方降温
```

若多个时段都出现这一序列，优先减少追加消息和即时表态压力，并在双方能接收信息时澄清节奏。减速是停止加压，不是惩罚性沉默；单次延迟不能确认追逃循环。

**静默的方向性（把「谁在冷处理」变成可算的数）**：对每一段长静默（建议阈值 ≥24h，取最长的 5–8 段）记录两件事——① 这段静默**由谁最后发言后开始**；② 这段静默**由谁重新开口打破**。然后按下面三种组合读：

| 组合 | 读法 | 相处含义 |
|---|---|---|
| 静默多由 A 发起、也由 A 打破 | A 可能有分区离线、忙碌或按自身节奏恢复联系的习惯 | 不能据此排除兴趣下降；结合说明、兑现和其他情境核验 |
| 静默多由 A 发起、由 B 反复追问打破 | 存在追逃循环候选 | 检查追问是否持续增加压力；减少追加并择机协商 |
| 静默多由 A 发起、B 从不追问 | 聊天记录中未出现追逐 | 不推断 B 一定平静或一定反刍；主观影响需直接询问或由用户补充 |

静默组合只能描述谁结束和重启会话，不能证明冷处理、爱意、撤离或内心反刍。报告需标注聊天记录看不到的主观体验，并把行动写成可拒绝的节奏协商。

## 二、高唤醒行为不等于爱意

吃醋、占有、情绪起伏、暴露脆弱、反复试探、触碰边界、忽冷忽热和退缩都属于**非特异行为**：它们可能与喜欢有关，也可能来自焦虑、控制欲、压力、冲突习惯、回避、兴趣下降或其他现实事件。不能把“越闹越爱”“越逃越爱”当作默认解释。

| 可见行为 | 可以确认 | 不能直接推出 | 必须同时检查 |
|---|---|---|---|
| 吃醋、要求偏爱、限制异性往来 | 对排他性或注意力分配有反应 | 深爱、专一或合理控制权 | 双方是否有明确排他约定；表达是否尊重自主权 |
| 在用户面前脆弱、幼稚、发脾气 | 愿意或不得不暴露某种情绪状态 | 信任很深、接受全部或害怕失去 | 是否也能承担情绪责任、接受安抚之外的边界与协商 |
| 假装冷淡、提异性、测试包容度 | 存在间接确认或影响反应的行为 | 因为上心、只是缺安全感、可以被原谅 | 是否愿意改为直接表达；是否反复制造焦虑或越界 |
| 靠近后退缩、停止回应、再次回来 | 互动节奏发生变化 | 越爱越逃、一定会回头或正在考验用户 | 触发事件、外部压力、明确表述、后续修复和持续投入 |
| 情绪稳定、温和、不吃醋 | 当前没有通过冲突表达占有 | 不爱、无所谓或已经放下 | 是否稳定关心、可靠回应、尊重边界并兑现承诺 |

### 判断门槛

- 单个高唤醒行为只记录为事实，不给“真爱信号”标签。
- 多个同类行为反复出现，优先判断互动模式和风险，不把频率当作爱意强度。
- 支持“存在关系投入”的证据应来自多类、持续且可核对的行为：明确表达、双向发起、时间与现实投入、尊重拒绝、承诺兑现、冲突后修复和共同计划。
- 有强烈情绪但缺少尊重、责任和修复时，结论是高唤醒或关系不稳定，不是“爱得更深”。
- 平静稳定也可能来自安全感、成熟沟通或稳定承诺，不能把戏剧性当作感情真实性的必要条件。

### 双轨应用

- **轨 A**：检查占有、试探或退缩是否削弱用户选择空间、增加解释成本或越过边界；不奖励测试，不用反向吃醋或冷处理回应。
- **轨 B**：列出字面行为、情境和至少一个替代解释；无法从材料确认喜欢、自卑或害怕失去时明确写“心理动机未知”。

## 三、Sternberg 爱情三角

**关键前提：这里打的是「在这份语料里可观测到的互动表现强度」，不是「爱不爱」的量表。**
得 0 分不代表没有，只代表这份聊天记录里没有可观测证据。这一点必须在报告里写清楚。

### 三个维度的指标来源

| 维度 | 主要指标 | 辅助线索 |
|---|---|---|
| **亲密** | 双向 `question_ratio`、回应率、`char_p90`（自我披露深度）、日常分享频率 | 情绪词双向流动、共同记忆的引用 |
| **激情** | `night_ratio`、秒回比例、邀约类话题、暧昧/亲密表达、emoji 与称呼 | 话题的专属感、照片/语音的双向使用 |
| **承诺** | 明确关系表述、共同未来计划、排他性表达、稳定性（`momentum_recent_vs_base` 平稳） | 公开化线索（提及他人/共同社交） |

### 证据等级

每个维度只使用定性等级：

- **证据充分**：多类行为在多个可比较情境中持续一致，并有直接引文或约定兑现。
- **证据混合**：存在明确表现，但持续性、方向或来源不一致。
- **证据有限**：只有零星、单一类型或高度依赖情境的线索。
- **未观察到**：当前材料没有相关证据；不等于现实中不存在。

每个等级附具体证据和反例。输出可以描述“亲密证据较多、承诺证据有限”等形状，不能把三维计算成爱意分数。

### 常见形状

| 形状 | 含义 | 典型风险 |
|---|---|---|
| 激情高、亲密承诺低 | 热但浅 | 激情消退后无支点 |
| 亲密高、激情低 | 陪伴型/朋友区 | 难以推进 |
| 承诺高、亲密激情低 | 空壳关系 | 形式化维持 |
| 三项均衡且高 | 完整型 | — |

## 四、Gottman 沟通质量

### 1. 正负互动概况

统计（由模型阅读语料完成，脚本不统计）：

**正向**：幽默、赞同、欣赏/感谢、共情回应、主动关心、接住对方话题并延伸
**负向**：批评（抱怨对方这个人）、蔑视（讽刺/嘲笑/贬低）、防御（辩解/反怼/撇清）、筑墙（沉默/敷衍/转移话题）

报告观察窗口、正负互动候选数量、代表性原文和相较前一窗口的变化。不得把 `5:1` 或其他固定比例当作私聊关系的通用健康阈值；候选必须人工复核，频次也不能替代内容、严重度和修复情况。

### 2. 四骑士（中文聊天的典型形态）

| 骑士 | 聊天里的样子 | 危害 |
|---|---|---|
| 批评 | 「你总是……」「你从来不……」 | 把事件升级为人格指控 |
| 蔑视 | 直接贬低对方人格、持续优越或羞辱 | 反复出现且无修复时是高关注风险；单次候选先核语境与对象 |
| 防御 | 「不是我的问题」「我也很累」 | 阻断修复 |
| 筑墙 | 已读不回、敷衍、转移话题、突然消失 | 让对方失去所有修复入口 |

#### ⚠️ 蔑视判定前必须先做「指向对象分类」（硬性步骤）

中文聊天里粗口密度高 ≠ 蔑视。**只要出现脏话/贬损词，必须逐条回看上下文，归到下列五类之一，只有第 1 类计入蔑视：**

| 类别 | 例子 | 计入蔑视 |
|---|---|---|
| ① 指向对方人格 | 「你个废肥」「你懂个球」「你真笨」 | ✅ 计入 |
| ② 指向工具/物件 | 「废物」（在评价某个 SKILL/软件时说） | ❌ |
| ③ 指向第三方 | 「他当我傻子」「这是傻逼」（在骂同事） | ❌ |
| ④ 自指 | 「我是不是傻」「我废了」 | ❌ |
| ⑤ 拒接抬举/自谦 | 对方夸你时回「滚」「滚，我会？」 | ❌ |

**实操要求**：
1. 先把全量粗口（含「傻逼/废物/废/滚/懂个球/神经病/有病/笨/蠢」）grep 出来，**逐条带上下文读**，不要只看词表命中数；
2. 统计真正指向对方人格的候选，并同时记录前后语境、对方反应、是否道歉或修复；
3. 不设置千分比阈值自动判定成立或不成立。低频但严重、持续影响边界的羞辱仍需标记；高频但双方明确接受的口语也要保留对具体影响的核验；
4. 对象不明或语境不足时写“无法分类”，不把词典命中直接定性为蔑视。

判错代价很高：把口语习惯误判为蔑视，会让整份报告的「最大风险」指向错误的方向。

### 3. 情感投标（bids）—— 最实用的一项

**投标** = 一方发起的小互动：分享一张图、抛一个小问题、提一个话题、一句关心。
对方的回应只有三种：

- **转向（toward）**：接住并延伸 → 加分
- **背离（away）**：忽略、敷衍、转移 → 扣分
- **对抗（against）**：反感、反击 → 重扣分

统计时明确窗口，抽取最近一组可识别的小互动，分别列出转向、背离和对抗的例子。可以报告样本内比例用于描述变化，但不使用 `70%/40%` 等固定阈值宣判情感账户健康或枯竭，也不声称它能单独预测关系走向。

用户可以改善自己的回应方式，但关系质量仍需要双方参与；若对方持续不回应、对抗或越界，不能把修复责任单独交给用户。

## 置信度规则（每条结论都要标注）

| 置信度 | 条件 | 写法 |
|---|---|---|
| 高 | 多类独立证据跨情境一致 + 有原文与反例检查 | 「当前材料稳定呈现 X 模式（证据完整）」 |
| 中 | 一类明确证据 + 部分佐证或情境限制 | 「可能为 X（证据有限）」 |
| 低 | 只有间接线索或样本不足 | 「待验证假设：X。可用以下方式验证：……」 |

低置信度的结论要**同时给出验证方法**（例：「下次主动开启一次话题，观察对方是否接住并延伸」），而不是含糊地抛给用户。

## 高危内容提示

正常输出关系分析与策略；出现以下信号时，**额外**附一句关注提示，不必中断分析：

- 自伤、自杀、长期抑郁的表述
- 控制与监视（查岗、要求报备、限制社交）
- 纠缠、威胁、骚扰
- 财物诈骗迹象

提示方式：指出观察到的具体信号 + 建议寻求专业帮助（心理咨询 / 相关机构），安全相关议题建议同时向身边可信的人求助。
