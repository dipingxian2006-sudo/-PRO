# V2 双轨分析与双结果输出协议

关系策略任务必须基于同一份已核验事实，同时完成两套独立分析。双轨不是正反辩论，也不是把相同建议换标题重复一遍。先按 [逐句双轨协议](goutou-utterance-dual-analysis.md) 覆盖范围内每个分析单元，结果 A/B 只能聚合这些逐句结果。

## 轨 A：关系优势与主动权策略

目标是帮助用户维护合理利益、个人边界、独立性、主动权、选择空间及长期互惠位置。

分析：

- 双方可观察的投入，包括时间、发起、回应、承诺兑现、现实资源与情绪劳动；消息数量不自动等于投入质量。
- 谁在提出需求、谁能拒绝、谁承担等待和调整成本，以及规则是否由双方协商。
- 用户当前的选择空间、替代方案、时间成本和不可让渡边界。
- 哪些行动能增加清晰度、互惠和可退出性，而不是增加对方的不确定或依赖。
- 是否存在礼物或照顾形成的隐性债务、过去承诺被用来升级要求、群体/权威压力、虚假稀缺或沉没成本；过去的同意不得替代当前选择。
- 公开表态、朋友或家人意见、群聊和权威身份是否压缩用户的自由选择；重大决定是否能在低压力、可拒绝的情境下重新确认。
- 反复互动中，用户是否在反馈尚未出现前连续加码、突然大幅撤退，或长期独自承担澄清与修复成本。
- 吃醋、占有、试探、触碰边界或退缩是否增加用户的解释成本、限制选择空间或形成单向情绪劳动；这些行为不能因为可能来自喜欢而免于边界判断。

“优势”指用户有清楚信息、真实选择、稳定边界和不过度单向投入；不指压过对方、赢得争执或让对方更焦虑。可以建议放慢投入、明确条件、要求对等行动、保留自己的生活安排或退出不互惠的协商。不得欺骗、惩罚性冷处理、制造嫉妒、虚构稀缺、操控依赖、解释轰炸或越过明确拒绝。

固定字段：

1. 当前优势与劣势。
2. 双方投入及主动权的可观察证据。
3. 用户需要维护的利益与边界。
4. 推荐行动及停止条件。

## 轨 B：客观理解与双向沟通

目标是准确理解现实，区分事实与推测，呈现双方可能的立场、利益和感受，并改善可拒绝、可协商的表达。

分析：

- 已确认的原话、行为、时间范围、约定和来源。
- 双方各自可能的合理关切，并为每项解释保留至少一个替代解释。
- 误解、认知偏差、冲突触发、沟通时机和长期兼容性中的可验证部分。
- 将口头态度、实际选择和后续兑现分开，并同时检查个人倾向与情境因素；心理学机制只作为候选解释，不直接确定动机。
- 对反复拉扯先还原“触发—行动—回应—延迟—解释—补偿—下一轮”，区分共同形成的模式与故意操控；缺少环节时保留未知。
- 将公开表达、私下表达、现实选择与后续兑现分开；重复、鲜明故事、群体一致和身份声望可以提高显著性，但不能证明事实或真实意愿。
- 哪些心理动机、感情强度、人格或记录外事件无法确定。
- 将吃醋、脆弱、试探、忽冷忽热和退缩作为非特异行为：可以讨论喜欢、焦虑、控制、压力、回避或兴趣下降等候选解释，但不能用行为本身证明爱意。

客观不等于平均分责。若证据显示一方明确失约、施压或长期单向获益，应照实写；同时区分事实、影响和动机。理解对方的关切不等于要求用户认同、服从或放弃边界。

固定字段：

1. 已确认的事实。
2. 双方可能的合理关切。
3. 尚无法确定的心理动机。
4. 沟通建议及停止条件。

## 共同证据与边界

- 两轨使用同一事实账本、时间范围、说话人归属和引文；不得为支持不同结论选择性改变事实。
- 两轨都受隐私、自主权、共同承诺、明确拒绝和同意边界约束。
- 推测必须标为推测；轨 A 的“主动权”也不能用未回复、字数或单个表情测量。
- 证据不足时保留字段并写“无法评估”，同时说明所缺材料。不得因为轨 A 缺证据而虚构博弈，也不得因为轨 B 缺证据而虚构双方感受。
- 两轨可以得出不同侧重点。若建议冲突，明确写出权衡：用户维护什么利益、可能付出什么关系成本、哪些反馈会触发改道。

## 模式深度

| 模式 | 双轨深度 |
|---|---|
| QUICK | 每轨 1–3 个高信息点；各自保留停止条件，然后给一个 A–E 行动代码 |
| SNAPSHOT | 完整固定字段；所有阶段性判断降级为待验证假设 |
| FOCUSED | 只使用指定窗口；可对照一个同长度窗口，不外推长期主动权或兼容性 |
| FULL | 完整固定字段，并引用四种分析方法中可复核的证据 |
| ASSESSMENT | 不强制双轨；只解释测评质量和分数，除非用户另提供互动材料并明确要求关系策略 |

## 综合行动建议

在两轨之后可以给一项综合行动建议。优先选择既维护用户合理利益、又尊重对方自主权的交集行动。若没有明显交集，写清两个可选方向及代价，不替用户暗中选择，也不删除前面的分歧。

用户询问怎么回复、怎么继续聊或如何推进时，不能停在分析结论；继续读取 [双轨聊天参谋协议](goutou-dual-track-chat-advisor.md)，把轨 A、轨 B 分别展开为方案一、方案二，再给 A–E 最终综合决策。
