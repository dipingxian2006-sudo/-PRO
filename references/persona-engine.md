# 人物画像引擎

给每一方输出一张画像卡。**每张卡上的每一句结论都必须带证据**——一句没证据的画像等于偏见。

证据来源两类：
1. **指标**：`metrics.json` 里的数字（引用具体值，不要只说「偏高」）
2. **原文**：聊天里的原句或行为片段（引用时可用代号）

---

## 12 个行为维度（另有可选第 13 项：性格与类型）

### 1. 沟通风格

从 `char_avg` / `char_p90` / `question_ratio` / `max_streak` 判断：

| 表现 | 风格 |
|---|---|
| 句长高、提问多、主动开启话题 | 展开型·探索式 |
| 句长短、回应率高、很少开启 | 应答型·配合式 |
| `max_streak` ≥3 | 独白型（倾诉需求强） |
| 大量 `[图片]`/`[表情]` | 图像型（文字表达意愿低） |

### 2. 情绪模式

从 `positive_hits` / `negative_hits` / `pos_neg_ratio` / `night_ratio`：

- 压抑后释放：平时中性，某次突然长篇负向表达
- 稳定正向：正向词持续、句长中等
- 情绪外放：正负词都高、波动大
- 情绪收敛：正负词都极低（**注意**：这也可能是低投入）

### 3. 投入模式（最关键）

四个指标一起看，**不要只看条数**：

```
发起意愿  → initiated_sessions / initiative_share
接住意愿  → response_rate
回应速度  → reply_latency_median_sec
表达深度  → char_avg / char_p90
```

四种典型组合：

| 发起 | 接住 | 深度 | 判断 |
|---|---|---|---|
| 高 | 高 | 高 | 双向高投入 |
| 高 | 低 | 高 | 单向输出（对方在配合，不在投入） |
| 低 | 高 | 低 | 被动回应型（愿意接，但不主动） |
| 低 | 低 | — | 抽离中 |

### 4. 回复规律

从 `peak_hours` / `reply_latency_*` / `night_ratio`：作息时段、是否只在某时段活跃、延迟是否随时间变长。

**必须做的一步**：把延迟拉长和作息变化对照。凌晨 2 点发的消息 8 小时后回，是正常的；工作日下午发的消息 8 小时后回，是信号。

### 5. 冲突模式

从负面事件附近的消息结构看：是解释、回避、反击、还是冷处理。

| 模式 | 特征 |
|---|---|
| 解释型 | 冲突后长篇说明理由 |
| 回避型 | 冲突后延迟变长、话题转移 |
| 反击型 | 立即回击、正负比骤降 |
| 冷冻型 | 直接沉默，下一段对话才重新开口 |

### 6. 关系需求

从提问内容与话题方向推断：确认感（反复问「你到底怎么想」）、陪伴感（高频日常分享）、空间感（少回应但不切断）、新鲜感（主动制造新话题/邀约）。

### 7. 兴趣与生活线索

从聊天内容里提取：提到的地点、食物、爱好、工作节奏、朋友圈。**这些是话术的素材来源**，提取时要具体到可引用的细节。

### 8–10. 消费 / 社交 / 价值观（可选扩展）

仅在数据里有足够线索时填写，没有就写「数据不足」——不要脑补。

### 11. 情绪触发点

**喜欢的方式**：什么话题/时机下对方条数变多、句长变长、正向词上升。
**抗拒的方式**：什么话题后延迟变长、敷衍率上升、或出现转移话题。

用「前后对比法」找：把每个话题切换点前后的 3 条消息指标做对比，差异最大的就是触发点。

### 12. 最佳沟通方式 + 禁区

- **最佳方式**：时段（用 `peak_hours`）、话题（用兴趣线索）、句式（提问 vs 分享）、长度（≤ 对方上一条字数 × 1，见 strategy-playbook 字数红线与话术建议第 2 项）
- **禁区**：从抗拒模式反推。例：对方对连续追问敏感 → 禁区是「一天内多次问同一件事」

## 画像卡模板

```markdown
### 人物画像：{代号}（{真实名}）

| 维度 | 判断 | 证据 |
|---|---|---|
| 沟通风格 | 应答型·配合式 | char_avg 8.1 字，question_ratio 0.29 |
| 情绪模式 | 情绪收敛 | 正向 4 / 负向 1，句长短 |
| 投入模式 | 抽离中 | 收尾占比 0.21，回应率 0.28 |
| 回复规律 | 白天零星，深夜偶发 | peak_hours=[9,12,22] |
| 冲突模式 | 回避型 | 被追问后延迟从 36s → 46h |
| 关系需求 | 空间感 | 「再说吧」「最近有点烦」 |
| 兴趣线索 | 日料、展览 | 8/2 提及鳗鱼饭、展览 |
| 情绪触发点 | ✅ 轻松日常分享 ❌ 连续追问计划 | 8/2 追问周六安排后冷淡 |
| 最佳沟通方式 | 晚间、短句、不带要求 | — |
| 禁区 | 追问确定计划、要求明确态度 | — |
```

## 第 13 项：性格与类型（**必带 · 用户要求画像必须含性格与性格缺点**）

性格定性、荣格八维分型、MBTI、大五**都在分析范围内**（详见 `references/jungian-typing.md`）。
**本项是画像卡的必带项**——用户明确要求「根据人物性格、以及性格缺点给出具体方案」，没有这一项，后面的方案层与四层方法分析法都失去锚点。

画像卡必须把性格拆成**两个子维度**，缺一不可：

| 子维度 | 用途 | 在方案里怎么用 | 举例（高焦虑型） |
|---|---|---|---|
| **性格优点（可倚仗的入口）** | 方案要**顺着它走** | 哪些特质可作为推进关系的"抓手"——她愿意暴露、愿意接的入口 | 直球坦诚、主动示弱、重承诺、私下放开 |
| **性格缺点 / 雷区（方案必须规避触碰的）** | 方案要**绕开它** | 哪些特质是"踩了就炸"或"盲区"，任何动作触发它即判违规（R4 性格定制） | 反刍放大（一句差评被放大成一整天的安心缺失）、公开场合缩、需确定性 |

> **写法纪律**：「性格缺点」是**关系动力学描述**（触发条件 + 连锁后果），不是道德评价。写清"在什么条件下、引发什么连锁"，**禁止贴「作 / 闹 / 难搞」类标签**——那会诱导出打压话术，违反 R3。

画像卡模板升级（在「性格与类型」段补两张表）：

```markdown
### 性格与类型：{代号}

| 维度 | 判断 | 证据 |
|---|---|---|
| 荣格功能栈 | {主导}-{辅助}-{第三}-{劣势}（置信度{}） | … |
| MBTI 类型 | {XXXX}（置信度{}） | … |
| 大五 OCEAN | O{高/中/低} C{} E{} A{} N{} | … |
| Grip 表现 | 承压时 → {…} | … |

**性格优点（入口）**：{…}
**性格缺点 / 雷区（规避）**：{…} —— 触发条件：{…}；连锁后果：{…}
```

两个模型（荣格 / 大五）结论一致时置信度上调，冲突时如实列出分歧，不强行统一。

## 表述纪律（吸收 schema 2.0）

- **双方都建卡**，避免只寻找对方的缺点。可记录对沟通有帮助的行为、反复出现的摩擦、明确表达的不愿意。
- **区分「自述事实」与「解释」**：对方自述忙是「自述事实」；**忙是否解释某次互动仍是待验证解释**。表达压力**不是**对用户抗拒。
- **说"在这段记录里多用短句"比直接判"冷淡"更可靠。** 每项列：观察 / 消息 ID / 可能解释 / 替代解释 / 什么新证据会推翻。
- **因果检查**：按时间核对谁先说、谁回应谁；没有可靠时间时只描述文件中顺序。区分"这句话后出现变化"与"这句话造成变化"。**替代原因不能从聊天中排除时，保留多个解释**，不能把"无法排除 A"升级为"A 与 B 都造成"。
- **依恋与动机保持为假设，不给心理诊断。** 对方明确说的关系定义可引用；**其内心态度不是可直接读取的事实。**

## 三条硬规则

1. **宁可写「数据不足」，不要脑补。** 一个维度没有证据就空着，空着比编的强。
2. **区分「不擅长」和「不愿意」。** 有人天生话少但每条都认真回（`response_rate` 高、`char_avg` 低）——这是内向，不是冷淡。两者策略完全相反。
3. **画像要可证伪。** 每句结论后面必须能回答「什么数据会推翻这个判断」。答不上来就说明这句是主观印象，删掉。

4. **方案必须挂性格 / 雷区推导（与 R4 联动）。** 凡由画像推导出方案、话术或"该做什么／不该做什么"时，**每条都必须注明「针对她哪条性格优点或雷区」**——只写"多关心""少追问"而不说明针对哪条性格，视为未过检。性格缺点（雷区）清单是方案层的"禁区地图"：动作若落在雷区触发条件上，直接判违规，不进交付。
