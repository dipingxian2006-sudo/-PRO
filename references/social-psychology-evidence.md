# 社会心理学证据迁移协议

用于关系分析中的归因、社会影响、从众、承诺一致性、态度与行为、友谊和爱情模型。它提供解释检查，不提供读心结论，也不把实验效应改写成操控话术。

## 一、先判断证据能回答什么

按以下顺序使用证据，后一层不能覆盖前一层：

1. **直接事实**：原话、实际行为、约定、拒绝、兑现、时间和现实成本。
2. **重复模式**：多个可比较情境中反复出现的发起、回应、协商、修复和边界行为。
3. **情境机制**：压力、群体规范、不确定性、既有承诺、资源限制等可能影响行为的条件。
4. **心理学模型**：用于提出候选解释和反证问题，不用于确定个人动机、人格或感情强度。

经典实验、教材概念和群体平均效应不能单独预测某个具体的人。研究结果来自何种样本、任务和情境不清楚时，只能写“可能相关”，不能写“因此她/他一定……”。

## 二、七项关系分析规则

### 1. 人与情境必须同时解释

同一行为可能由个人目标、当时情境、双方互动和文化规范共同产生。把“回复少”“退缩”“情绪大”直接归为冷漠、回避型、深爱或慕强，属于过早的人格归因。

- 每个重要心理解释至少列一个情境性替代解释。
- 优先比较同一个人在不同情境中的变化，而不是把一次行为固定成人格。
- 如果外部压力、可用性和互动触发没有资料，写“无法区分个人倾向与情境影响”。

### 2. 态度、自述和行为分开记账

口头态度、假设性回答和自我形象不必然预测真实情境中的行为。关系判断分别记录：

- **表达**：说喜欢、说重视、说以后会怎样。
- **选择**：实际是否发起、留时间、协商、拒绝或退出。
- **兑现**：约定是否持续落实，冲突后是否修复。

表达可以是证据，但不能替代选择和兑现；行为也要结合成本、机会和边界判断，不能把一次顺从当作稳定承诺。

### 3. 承诺一致性和认知失调不是爱意证明

人可能为了与既有选择保持一致而提高信心、寻找理由或继续投入。这个机制可以解释自我合理化风险，但不能推出“投入越多越爱”“答应过一次就会继续答应”或“制造沉没成本能稳住关系”。

- 新决定必须允许重新考虑，过去的同意不能代替当前同意。
- 区分真实收益、自由选择与为了证明过去没错而继续。
- 发现沉没成本时，问题是“从现在开始是否仍值得”，不是“已经付出多少所以必须继续”。

### 4. 六类影响机制只用于识别压力和改善透明度

| 机制 | 关系中的可观察风险 | 合规处理 |
|---|---|---|
| 互惠 | 礼物、照顾或让步被当成对方必须回报的债 | 付出不附隐藏条件；需要回报时直接协商 |
| 承诺与一致 | 用过去的一次同意、公开表态或小承诺逼迫继续 | 每一步重新确认；允许改变主意 |
| 社会认同 | 用朋友意见、别人都这样或异性竞争替代双方判断 | 回到两人事实、意愿和边界 |
| 喜好 | 因亲近、相似、赞美或熟人关系而降低审查 | 喜欢不等于同意；请求保持清楚可拒绝 |
| 权威 | 用专家、家长、导师或心理标签压过当事人选择 | 权威信息只作参考；决定权仍属于当事人 |
| 稀缺 | 因怕失去、时间限制或竞争而仓促决定 | 核实限制是否真实；不给虚假倒计时或嫉妒刺激 |

这些机制能提高顺从的可能性，不等于提高真实喜欢、兼容性或长期稳定性。不得把它们改造成“让她猜”“冷热周期”“征服”“展示竞争”的执行方案。

### 5. 从众、规范与权威不等于真实意愿

人在不确定、群体一致或权威明确时可能改变公开反应，甚至与原有判断不一致。因此：

- 区分“对方个人想要什么”和“家人、朋友、平台内容要求什么”。
- 群体意见可以解释压力，不能证明群体判断正确。
- 公开场合的顺从不能自动视为私下同意；涉及关系定义、性或重大承诺时需要当事人的自由表达。

### 6. 社会认知会选择性加工信息

注意、解释、判断和记忆都可能受期待、自我保护、情绪和既有立场影响。用户和分析者都可能只看见支持原假设的片段。

- 先写可证伪的假设，再搜索支持证据与反例。
- 对“她就是在试探”“他是因为自卑”等结论，至少提出一个不同方向的解释。
- 事件后尽快记录原话与行为；后来的感受不能改写当时事实。

### 7. 关系模型描述维度，不生成个人真值分数

友谊与亲密关系可以观察互相回应、支持、自我披露、交换/共享倾向、亲密、激情和承诺等维度。但因素分析或群体研究只能帮助组织现象，不能给某段关系计算“爱意 78%”。

- Sternberg 三维用“证据充分 / 混合 / 有限 / 未观察到”描述，不打 0–100 分。
- 正负互动和情感投标报告观察窗口、例子和变化，不套通用阈值宣判关系健康或枯竭。
- 激烈情绪、嫉妒和稀缺感不等于亲密；稳定、可预期和尊重拒绝同样可能是投入证据。

## 三、双轨应用

### 结果 A｜关系优势策略

检查是否存在隐性债务、承诺升级、群体压力、权威压制、虚假稀缺或沉没成本。优势来自知情、可撤回的选择、真实替代方案和边界，不来自让对方机械顺从。

### 结果 B｜客观关系与双向沟通

把个人解释与情境解释并列；把表达、选择和兑现分开；明确哪些机制只是可能相关。沟通建议优先直接说明请求、理由和拒绝空间。
