# V2 逐句双轨分析协议

所有关系分析先逐句完成 A/B 双轨标注，再生成日报、总结、聊天参谋和四种方法的聚合结论。逐句双轨与词典心态标签不是同一件事：词典结果只能作为候选证据，不能替代两轨解释。

## 分析单元与覆盖

- 默认以一条聊天消息为一个单元，沿用解析器消息 ID、说话人、时间和源文件定位。
- 一条消息含多个可独立判断的句意时拆为 `.s1`、`.s2`；换行、标点或表情不自动等于新句意。
- 引用、转述和用户自己的评论要区分层级，不能把被引用者的话算成当前说话人的立场。
- 图片、语音、撤回等不可读内容仍占一个单元，写“媒体内容未读取，A/B 均无法解释”，不能猜内容。
- 覆盖统计必须给出原消息数、分析单元数、已完成双轨数、无法解读数和未归属数。已完成双轨数应等于分析单元数；未归属内容单列，不冒充分析完成。

## 每句固定结构

```text
单元：m000123.s1｜说话人｜时间/源定位
原文：……
A 轨｜关系优势：可观察的投入、发起、回应、成本、选择空间或边界；对用户策略的局部含义。没有信号就明确写无。
B 轨｜客观共情：字面事实；双方可能的合理关切；至少一个适用的替代解释；仍未知的心理动机。只够确认字面时就停在字面。
局部动作：仅在该句直接影响回复决策时标 A–E 候选，否则写“无独立动作代码”。
```

### A 轨逐句判断

只回答该句对投入、主动权、互惠、规则协商、用户选择空间和边界的可观察含义。单句不能证明稳定优势、高位、依赖或长期投入；回复速度、字数、表情和称呼不得单独定性。

### B 轨逐句判断

先释义字面功能，例如提问、回答、分享、收尾、拒绝、纠正、玩笑候选或现实待办。再列可能关切和替代解释。没有足够上下文时写“不知道”，不补对方感受、动机或关系意愿。

## 汇总与引用

- 日报、阶段总结和结果 A/B 的每项判断引用一个或多个逐句单元 ID。
- 汇总可以概括重复模式，但不能推翻逐句事实；出现冲突时回到原文并标记人工复核。
- “未观察到信号”不等于“证实不存在”；未回复也不是一句可供心理分析的对方消息。
- 对一句话的 A/B 分析可以得出不同侧重点，但必须共用同一原文、说话人和上下文窗口。

## 模式输出

| 模式 | 逐句双轨交付 |
|---|---|
| QUICK | 对用户贴出的每个句意给一行 A/B 简版，再给方案一、方案二和最终决策 |
| SNAPSHOT | 正文列出全部单元的 A/B 表，再做有限汇总 |
| FOCUSED | 在指定窗口按时间顺序逐句列出，不以话题概括代替原句 |
| FULL | 主报告引用单元 ID；完整逐句双轨表作为附录或独立私密文件交付 |
| ASSESSMENT | 仅有测评时不适用；测评题目不当作双方聊天逐句分析 |

长记录若无法在单个回复中容纳，按连续时间段输出多个编号分块，明确每块起止 ID和整体覆盖进度；不得使用 Top-N、关键词命中或模型主观挑选代替完整覆盖。输出含私人聊天，放在任务私密目录，不提交技能仓库或公开位置。
