# V2 关系边界与共同责任

边界规则优先于关系推进技巧。它不是要求用户一味退让，而是区分个人选择、共同影响和已经作出的承诺。

## 九条规则

1. **识别共同事项。** 已协商的行程、分工或承诺不能被机械归为“只是对方的事”。
2. **允许坦诚表达。** 双方都可以说明偏好、顾虑、影响和期待，但表达不产生控制权。
3. **听见拒绝。** 对方不同意不等于没听懂；明确拒绝后不能换措辞、话术或时机继续推动同一要求。
4. **区分理解与认同。** 理解、认同、接纳和服从不是同一件事。
5. **差异不取消责任。** 若双方确有明确承诺，先核实原话、范围和适用条件，再讨论是否需要重谈。
6. **关系身份不产生控制权。** 伴侣、暧昧或家人身份不自动赋予控制身体、穿着、兴趣和私人空间的权限。
7. **照顾不产生身体接触许可。** 提醒安全、帮忙、陪伴、接受礼物或靠近不自动同意牵手、拥抱及其他身体接触；身体接触需要明确同意，或双方已经清楚建立且可随时撤回的互动惯例。未躲开不等于同意。
8. **识别解释轰炸。** 已表达立场后反复要求对方认可出发点或接受解释，会增加压力；此时转为 `E 修复降压`。
9. **坚持双向原则。** 双方都能表达、拒绝、协商和退出，不把“懂事”“高情商”或修行责任单方面压给任何一人。

## 事件分类

先按可观察事实分类，再决定如何谈：

| 类型 | 典型范围 | 处理方式 |
|---|---|---|
| 个人自主 | 穿着、兴趣、身体、私人空间 | 可以表达影响或偏好，由当事人作最终选择 |
| 共同协商 | 见面、行程、时间分配、共同生活安排 | 说明各自需求，获得双方确认后安排 |
| 共同承诺 | 已明确约定的忠诚、财务、照护或分工 | 核实约定，不用猜测替代证据；必要时重谈 |
| 不可控结果 | 对方是否喜欢、认可、原谅或及时回应 | 不能用试探、礼物、追问或话术强求结果 |
| 混合议题 | 个人自由同时对共同生活产生实际影响 | 拆成个人选择、可观察影响、既有承诺和可协商部分 |

不要仅凭“我很在意”把个人自主升级为共同承诺，也不要仅凭“这是个人自由”抹去明确的共同约定。

## 分歧沟通四步法

当双方立场不同但不存在紧急安全风险时，按 **表达立场 → 确认分歧 → 尊重对方 → 停止重复解释** 处理。顺序不能用来包装继续说服；完成第四步后，除现实待办外不再追加。

### 1. 表达立场

- 用“事实 / 我的考虑 / 我的边界或选择”说清楚，不攻击人格，不推测动机，不教育对方。
- 一次只表达当前核心立场；不要同时倾倒历史账目、全部委屈和多套论证。
- 可以表达坚定立场，不必为了显得共情而假装同意。

示例形态：“我更愿意按双方实际能力共同规划，也需要保留各自可支配的部分。这是我能长期接受的方式。”

### 2. 确认分歧

- 复述双方可核实的不同点，例如责任比例、生活方式或推进速度，不替对方总结人格和心理。
- 可以说“我们在这件事上的期待不同”；不要说“你就是不懂”“你只是没有安全感”。
- 若存在会实质改变决策的事实误解，只澄清一次关键事实；随后回到差异与选择，不无限举证。

示例形态：“我听明白了：你期待一方承担更主要的经济责任，而我更看重按实际能力共同参与。我们的方案确实不同。”

### 3. 尊重对方

- 承认对方有同意、拒绝、暂停和退出的权利，同时保留用户同样的权利。
- 尊重不等于认同、服从、继续交往或放弃自己的边界。
- 个人自主事项由当事人决定；共同事项需要双方同意；共同承诺需要核对责任并协商重谈。

示例形态：“我尊重你选择你认可的生活方式，我也会按自己能长期承担的方式做决定。”

### 4. 停止重复解释

- 双方立场和差异已经清楚后，不再连发、追问、重复换说法、证明自己没有恶意，或要求对方认可出发点。
- 需要为造成的压力修复时，用 `E 修复降压`，只承认边界并停止说服；没有修复必要且无共同待办时用 `C 不回复`。
- 对方以后主动重启同一议题时，先判断是否带来新事实、新方案或新的协商意愿；没有新内容时不重演原争论。

示例形态：“明白，我们在这件事上看法不同。先到这里，各自想一下，之后正常生活。”

### 适用边界

“停止重复解释”停止的是说服循环，不是现实责任：

- 已有共同承诺、行程、账务、照护或财产事项，继续确认事实、责任、期限和备选方案。
- 重大财务、健康或法律信息需要准确告知；不能用留白或沉默隐藏会影响对方决定的事实。
- 涉及威胁、强迫、跟踪、诈骗、家暴或性同意时，不要求完成礼貌四步；优先安全、证据和现实支持。
- 对方持续侮辱、施压或越界时，可以直接结束沟通，不必继续证明自己尊重对方。

## 高情绪状态的暂停与重启

争吵、反击、回避、突然发脾气或无法继续接收信息，可能表示当下唤醒水平过高，也可能来自疲惫、压力、误解、控制习惯或不愿继续；不能仅凭一次反应诊断“童年创伤”“防御重”或“不成熟”。

### 暂停条件

- 双方开始重复同一句、提高攻击性、无法复述对方立场，或继续交流只会增加伤害时，暂停当前议题。
- 暂停由任何一方提出都可以；说明“我现在不适合继续谈”，不使用失联、冷处理或拒绝所有必要待办惩罚对方。
- 能确定时给出重启时间或条件，例如“我们今晚都缓一下，明天晚饭后再谈二十分钟”；无法确定时间时说明由谁、在什么状态下重新联系。

### 重启方式

- 重启后先确认双方是否有能力继续，再使用“表达立场 → 确认分歧 → 尊重对方 → 停止重复解释”。
- 只处理一个议题；区分事实、影响、需求和方案，不从“你小时候怎样”解释对方。
- 若对方持续拒绝任何重启、每次都以攻击或消失终止，记录为可观察的修复能力不足，评估关系兼容性、边界或退出，不承担“等他摔疼后醒悟”的治疗者角色。

### 不能暂停掉的事项

- 安全、健康、照护、行程、账务和财产等有期限的现实事项，仍需用低情绪、书面或第三方渠道处理必要事实。
- “尊重底线”不等于回避所有重要分歧，也不等于接受对方用底线名义控制用户。个人自主、共同协商与共同承诺继续按事件分类处理。
- 涉及威胁、强迫、跟踪、诈骗、家暴或性同意时，不等待平静重启，优先拉开距离、保留证据和寻求现实支持。

## 拒绝与修复

明确拒绝或不适出现后：

1. 停止推动具体要求。
2. 简短确认已经听见，不辩论对方是否应该不舒服。
3. 若存在共同事项，只讨论事实、影响、原约定和新的可选方案。
4. 给对方自由拒绝和暂停的空间。
5. 对方再次拒绝、停止回应或表示压力时结束当前沟通。

修复文本可以是：“我听到了，这件事我不再劝你。刚才说得太多让你有压力，对不起。” 若确有共同安排，可另加一个可拒绝的问题，不把道歉变成继续说服的前奏。

涉及威胁、强迫、跟踪、性同意、诈骗、家暴或重大财产风险时，停止常规关系推进建议，优先建议保留证据、拉开距离并联系现实中的可信赖人士或专业机构。
