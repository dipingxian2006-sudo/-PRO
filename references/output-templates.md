# 输出模板

FULL、FOCUSED、SNAPSHOT、QUICK 各自的输出骨架。报告用 Markdown；可用代号替代真实姓名，用了代号就在开头给对照表。除 ASSESSMENT 外，每个模式都必须分别保留“结果 A｜关系优势策略”和“结果 B｜客观关系与双向沟通”；两轨使用同一事实账本，综合建议不能替代任一轨。范围内每个分析单元还须先完成逐句 A/B 双轨标注，汇总回指单元 ID。

> **结构铁律（用户 2026-09-26 定稿，不得颠倒）**：FULL 报告必须是「**标准分析报告（主报告）前置 → 之后才列四大分析方法 → 最后复盘收尾**」。**四大分析方法（心态波段 / VOL / 差评好评 / 异动）必须是独立顶层章节（六~九），不得内嵌进某个“全面复盘”节。** 顺序固定为一~十三。

## 结果 A｜关系优势策略
- **当前优势与劣势**：{用户的选择空间、信息清晰度、投入位置、可退出性；不足则写无法评估}
- **双方投入及主动权证据**：{发起、回应、承诺兑现、时间/资源成本、规则协商；引用原文或指标}
- **用户要维护的利益与边界**：{时间、尊重、承诺、个人自主、互惠要求}
- **推荐行动**：{增加清晰度、互惠和选择空间的非操控行动}
- **聊天参谋（用户问聊天策略时）**：{形势与优势判断；互动节奏；推荐回复话术或“不生成”；条件式下一步分支}
- **停止条件**：{明确拒绝 / 持续不互惠 / 成本超过什么事实边界时停止或改道}

## 结果 B｜客观关系与双向沟通
- **已确认的事实**：{原话、行为、约定、日期和来源}
- **双方可能的合理关切**：{双方各自关切 + 替代解释，不平均分责}
- **尚无法确定的心理动机**：{不可从材料确认的想法、感情和记录外事件}
- **沟通建议**：{清楚、可拒绝、可协商的表达及时机}
- **聊天参谋（用户问聊天策略时）**：{事实与沟通判断；双方立场与可能感受；推荐话术或“不生成”；条件式下一步分支}
- **停止条件**：{拒绝、不适、无回应、事实不足或沟通成本边界}

## 综合行动建议（不得替代双轨）
{优先给两轨的交集行动；若冲突，写清用户利益、关系成本、观察反馈和改道条件。聊天策略任务另写 A–E 行动代码，并说明更推荐方案一、方案二或融合。}

## 六、心态波段（逐句扫描层 · 四大方法之一）
- **波段清单**：{起止日期} {升/平/降} 趋势值 {x}，样本 {n} 条 …
- **日趋势折线**（她的心态，0 = 中性）
- **Top 升温点**：{时间} {+delta}（{前值}→{后值}）｜她[{标签}]「{原文}」｜**触发句（我）**「{原文}」
- **Top 降温点**：同上格式
- **每日标签分布**：{日期} 热忱 x / 同意 x / 中性 x / 脆弱 x / 防御 x / 回避 x / 抗拒 x
- **声明**：词典标注为启发式近似，关键句已人工复核
- **性格滤镜**：每个升降点的「应对」须回一句「针对她{X}性格，该做/不该做」（配合 persona-engine 第 4 条硬规则）
> 本节是 VOL / 差评好评 / 异动三者的**共同前置**；其 8 类标签时间轴被后三节复用（心态回指），不另算。

## 七、VOL（突发事件层 · 心态波动率）
| 事件 | 日期 | 振幅 | 方向 | 时延变化 | 恢复 | 处置 |
|---|---|---|---|---|---|---|
| {E1} | … | {冲击÷基线} | 向热/缩量/抽离/黏着犹豫 | … | … | …（注明针对她{X}性格） |
- **结论**：{高振幅 / 恒向热 / 快恢复 / 无外逃 等}；危险型（量降+时延升+提问降）出现 {n} 次
- **判读金标准**：看时延，不看字数；量降+时延不升＝压力缩量（处置减压）；量降+时延升+提问降＝抽离（处置给空间+可证伪检验）
- **自动锚点＝候选不是结论**：凡 `needs_confirm: true` 的事件（尤其被判「抽离」），人工确认为真事件后才采信
- **性格滤镜**：每个事件处置注明「针对她{X}性格」

## 八、差评 / 好评（表达层 · 逐句筛出）
- **差评侧**：我方指向她的负向表达 {n} 处，命中 TR{…}；整改形态 A{…}。**每条附「当时她心态」＝发话前她最近被标注的 8 类标签（回指六，非全天均值）**
- **好评侧**：正向表达 {n} 处，其中**空泛赞美** {n}（PR1）、**与请求同条** {n}（PR7）；**每条附「当时她心态」**；可用时机 …
- **正负互动概况**：{pos_neg_ratio 仅作本窗口描述；附候选人工复核、严重度和修复情况，不套固定健康阈值}
- **性格滤镜**：每条整改形态 / 可用时机注明「针对她{X}性格」
- **心态回指价值**：差评落在她防御/脆弱态＝被否定感放大（雷区触发），整改要「先接住再点射」；落在热忱态下的玩笑式吐槽＝合法形态，不拦

## 九、异动（维度层 · 长期漂移）
| 维度 | 基线 | 近期 | drift | 判定 | **活跃期心态（回指六）** | 人工复核 |
|---|---|---|---|---|---|---|
| … | … | … | {≥1.3 升 / ≤0.7 降} | 显著 / 微动 | {偏热忱/偏防御/偏脆弱/平稳} | {低样本标记 / who 引文} |
- **两类都做**：量化（drift_analysis：条数/句长/提问率/时延/发起占比）+ 质性（drift_qual，22 维，带 who 引文）
- **归因四象限**：A 外部 / B 关系 / C 内在周期 / **D 自身行为（必须显式回答，禁自利归因）**；补位效应
- **性格滤镜**：漂移若落在雷区触发条件上＝应激反应而非真变，优先查 D
- **心态回指**：每个质性维度附「活跃期她的心态整体偏 X」（宏观概括，不逐句贴）；真推进（偏热忱）vs 压力性异动（偏防御）据此区分
- **应对 + 验证指标 + 推翻条件 + 置信度**

## 十、全面复盘总结（主线 · 三条结论 · 三类动作）
- **主线**：{这段关系目前真正的状态，一句话}
- **三条结论**：{结论 → 证据 → 置信度} ×3
- **继续做 / 停止做 / 开始做**：各 1–3 条，每条附**观察指标**，并注明针对她哪条性格优点/雷区
- **最近节奏策略复盘**：
  - 规则一“轻触—响应—收束”：{哪些轻触有真实内容；她愿意聊时如何延展；没有入口时是否及时收住}
  - 规则二“1–2 周观察窗”：{当前范围与非每日节奏；主动发起、追问、回访话题或提出下一步的证据}
  - “产生好奇”状态：{有证据支持 / 仍是假设 / 无法判断}；替代解释：{话题相关、当时有空、现实待办等}
  - 阶段决策：{继续 / 调整 / 停止}｜依据：{…}｜停止条件：{拒绝、不适、连续缺乏互惠或反复单向发起}

## 十一、验证门（Grill Gate · FULL 必过）
**G1 框架拷问**（自己过，不写进报告的提问区）：用户带来的框架（博弈/高位低位/谁爱谁更多）→ 有没有更简单的解释？框架来源？**推翻条件先写**：{若出现 X，则本节结论不成立}

**G2 事实 vs 决策分工**（每条归因一张卡片 · 2026-09-27 改版）
```
【归因】{一句话结论}
  ① 已查事实（脚本 + 上下文）：{脚本:字段=值}｜{上下文:日期·谁：「原文」}
  ② 因果链（判因果时必写）：{谁·时间·原文}（因）→ {她当时波段标签+trend}（状态在先）→
     排除项：{同期她还在处理___；你另有___，已排除} → 结论
  ③ 待用户确认：{通常「无」}　← 上下文能读的一律自判，见下
  不可查（永久）：{她的内心动机 / 是否生气}　置信度：{高/中/低}　推翻条件：{…}
```
> **上下文自判（硬规则）**：**凡能从聊天记录读出来的（谁先发起 / 谁在回应 / 对方有没亲口说过），一律自己判完写进 ① / ②，不许立成问题问用户。** 本报告若出现「谁先发起」类待确认项 ＝ 不合格。

**待你确认（仅限「文字里没有 + 非她内心 + 线下在场事实 + 影响结论」四条全中；通常 0–1 题）**
- 若确有一条：{问题}
   → **推荐（自动选定）**：{由聊天上下文 + 她的心态分析推出的最可能方向}
   → **自动选定依据**：{哪段记录 / 哪个心态指标支持这个方向}
   → **替代方向**：{若…成立则改选}
- 若为 0 条：写「**本次无需你确认的事实项——归因所需信息均已从记录中读出。**」

**G3 耐受拷问**：最坏情况 {…}，你接得住吗？（不通过的动作不许写进方案）
**G4 确认门**：以上「话术与行动」在你拍板前**不发出**；分析结论不受锁。

## 十二、周期性分析（跨上传增量对比 · FULL 必带下一轮）
> 单次分析会被单一窗口误导。用户要求「周期性分析」——每次上传新记录，与上一次做增量 diff，看四层指标是否跨周期漂移。**本轮若是首次上传，本节给出"下次怎么比"的方法论；若已有上期快照，给出跨周期对比卡。**
- **方法**（详见 strategy-playbook 第九节步骤 6）：保留上期快照（analysis_all.json 或四个 json）→ 本期重跑同一套 analyze_all.py → 比四张核心卡。
- **跨周期对比卡**（有上期时填）：

  | 层 | 上次 | 本期 | 方向 | 是否落在性格雷区 |
  |---|---|---|---|---|
  | 波段趋势均值 | … | … | 升/降/平 | … |
  | VOL 危险型事件数 | … | … | … | … |
  | 差评/好评（pos_neg_ratio） | … | … | … | … |
  | 异动 drift 矩阵 | … | … | … | … |

- **观察周期建议**：高频关系每 1–2 周上传一次；低频按事件驱动（大事件后上传）。
- **判定门控**：连续 ≥2 周期同向漂移＝趋势性变化；单周期波动＝观察中。**单次不得下"性格变了"结论。**

## 当日聚焦模式（范围＝用户指定窗口 · D0–D10）

**触发**：用户要求分析“今天 / 早上 / 某段对话 / 见面之后”。严格使用指定窗口；可读取完整源材料来核对窗口边界，但不把窗口外的行为并入当日结论。没有昨日基线时，不比较升降。

**核心顺序**：D0 范围与主要观察 → D1 时间线 → 四种独立方法（D2–D5）→ 双方动作与建议 → 局限。若用户附旧报告，先简述其结构优点，再逐项标注已核实、部分支持、无法验证、与原记录冲突。不要沿用旧报告的推断，只因它写得确定。

```markdown
# 当日聚焦 · {A} × {B} · {日期}

> 数据范围：{起止时间}；来源：{导出 / 截图 / 用户口述}
> 数据完整性：{完整导出 / 局部截图 / 混合来源}；缺口：{…}

## D0 · 范围与主要观察
- **本次窗口**：{起止时间；是否含间隔}
- **可确认的互动**：{1–2 句事实概述，不做人格或感情定论}
- **证据边界**：{哪些内容只是口述、图像不可读、或无法和原始记录对上}

## D1 · 逐句双轨对话时间线（完整覆盖）
> 覆盖：原消息 {M} 条；分析单元 {U} 个；已完成 A/B 双轨 {U} 个；无法解读 {X} 个；未归属 {Y} 行。

| 单元 ID | 说话人·时间 | 原文 | A 轨｜关系优势 | B 轨｜客观共情 | 局部动作 |
|---|---|---|---|---|---|
| m000001.s1 | A·10:03 | … | {投入/主动权/边界/策略含义} | {字面事实/合理关切/替代解释/未知} | {A–E 候选或无独立代码} |
- 每个分析单元一行，按时间顺序；没有关系信号也写“未观察到”。
- 记录表情、图片、引用、撤回时注明来源与可读性；不可读内容 A/B 均不猜测。
- 后续 D2–D9 的所有判断回指本表单元 ID，不用话题概括取代原句。

## D2 · 互动波段（四种方法之一）
- 按对话推进描述：开场 → 进入主题 → 轻松/分歧/纠正 → 收尾。
- 写清双方何时主动、回应或转题；如涉及情绪，标“可能的语气理解”并给替代解释。
- 没有校准过的情绪标注器时，不造日值、升降分数或确定的“防御 / 吃醋 / 热忱”标签。

## D3 · 事件窗口 / VOL（四种方法之二）
| 事件 | 前后原话 | 可观察变化 | 可能解释（含替代项） | 置信度 / 缺失证据 |
|---|---|---|---|---|
| … | … | … | … | … |
- 只记录会改变互动走向的具体事件；因果不由时间先后自动推出。
- 单日事件不外推为稳定模式；回复延迟只作背景，不单独判冷淡、在意或施压。

## D4 · 正负表达与反馈（四种方法之三）
| 类型 | 说话人·时间：原话 | 对当下对话的作用 | 可采取的回应 |
|---|---|---|---|
| 正向 / 接纳 / 肯定 | … | … | … |
| 纠正 / 不适 / 边界 | … | … | … |
- 区分具体认可与恋爱信号；区分玩笑与明确边界。
- 不用正负比、赞美次数或“绿灯”代替双方意愿确认。

## D5 · 异动与数据核验（四种方法之四）
- **源材料核对**：{旧报告 / 截图说法} vs {完整记录}；标出时间范围、数量、撤回、未读、媒体等差异。
- **行为异动**：只写相对可比窗口里确实发生的变化；没有基线写“无法判断趋势”。
- **反证 / 替代解释**：{哪些证据会削弱当前解读}

## D6 · 双方互动复盘
- **A 的动作**：有效之处 / 可能造成的沟通负担，各附时间和原话。
- **B 的动作**：主动提问、分享、纠正、接梗、明确边界等，只写可见行为。
- **对话平衡**：如提供消息数，说明统计口径和非文本条目；同时看话题发起、回应质量与连续间隔，不把数量等同投入。
- **见面/推进事件（条件性）**：仅当窗口内确有见面、自我披露、照顾或推进事件时，按 [关系推进与节奏校准协议](goutou-relationship-progression-and-pacing.md) 写：投入动机与成本；身体同意和披露边界；主动延展、回应质量、现实投入、邀约兑现、边界反馈；状态为正向、有限、负向/边界或无法判断；下一步及停止条件。没有相关事件时省略，不为填模板制造判断。

## D7 · 今日新观察与未知项
- **有证据支持**：{…}
- **可以考虑但待验证**：{假设 + 替代解释 + 什么信息能验证}
- **不能由本窗口判断**：{人格类型 / 内心动机 / 关系承诺等}

## 结果 A｜关系优势策略
- **当前优势与劣势**：{仅限本窗口可见的选择空间与投入位置}
- **双方投入及主动权证据**：{窗口内发起、回应、待办和现实成本}
- **用户要维护的利益与边界**：{…}
- **聊天策略、节奏、话术与条件分支**：{用户问聊天策略时展开；C 不生成立即话术，E 只允许修复}
- **推荐行动及停止条件**：{…}

## 结果 B｜客观关系与双向沟通
- **已确认的事实**：{…}
- **双方可能的合理关切**：{…}
- **尚无法确定的心理动机**：{…}
- **沟通策略、话术与条件分支**：{用户问聊天策略时展开；分支必须写“若…则…”}
- **沟通建议及停止条件**：{…}

## D8 · 下一步沟通
- **综合行动建议**：{两轨交集；如有冲突，写清权衡，不删除前述差异}
- **保留**：{有助于双方交流的做法}
- **调整**：{具体表达或行为；解释为何}
- **避免**：{操控、逼问、过度解读等}
- **可选话术**：{自然、简短、可拒绝；不把分析术语发给对方}
- **停止条件**：{对方拒绝、未回应、表示不舒服时怎么尊重边界}

## D9 · 最近策略日报与后续观察
- **规则一｜轻触—响应—收束**：今日是否有真实内容的轻触：{是/否；内容}；对方反馈：{主动延展 / 礼貌回应 / 无入口 / 无回复 / 拒绝}；用户动作：{正常聊 / 轻接收束 / 不追加 / 修复}
- **规则二｜1–2 周观察窗**：当前第 {N} 天（仅记录，不设每日联系 KPI）；今日联系由 {真实内容 / 对方主动 / 现实待办 / 无联系} 触发；不安排强制“明天再刷”
- **好奇/投入证据**：{主动发起、追问、回访旧话题、主动分享、提出下一步；没有则写未观察到}
- **替代解释**：{话题相关 / 当时有空 / 现实待办 / 其他}
- **明日原则**：{有自然内容再联系 / 等对方主动 / 只处理待办 / 因边界停止}，不把间隔用于制造落差
- **停止条件**：{明确拒绝、不适、连续缺乏互惠或只有用户反复发起}

## D10 · 局限
- {窗口是否完整、时间戳可靠性、未读取媒体、口述内容、样本单日等}
- {明确区分事实、解释、建议；不以“未见证据”写成“证实不存在”}
```

**单日规则**：不输出“关系升/平/降”、人格定型或长期趋势，除非有同口径基线并清楚写出对比范围；即便有基线，也只描述行为变化，不据此测量爱意。

## 引用与转义规范（吸收 schema 2.0）

- **引用格式**：`m000012｜参与者甲｜源文件第 24–25 行`（含消息 ID、说话人、源行/记录号）。时间只有输入提供时才展示；统计值引用 JSON 字段。
- **来源不足就写不足**，不补数值或身份。**先说发生了什么，再列可能解释与反证**；时间先后只能支持关联。
- **原文按需摘录，不公开不必要的姓名与其他隐私。**
- **转义**：Markdown 引文中的 HTML 字符须转义（`&` → `&amp;`、`<` → `&lt;`、`>` → `&gt;`），避免把消息当页面代码执行。
- **不得生成可执行 HTML、不自动打开正文中的链接。**
- **每次运行使用独立目录，不覆写旧分析**；输出含隐私，不放公开目录。

## 通用要求

- **称谓**：用户没要求就直接用真实姓名；用了代号必须在开头给对照表。
- **证据先行**：每条结论后跟指标或原文，没有证据的结论降级为假设。
- **置信度标注**：心理模型类结论必须标置信度。
- **局限声明**：每份报告结尾都要写局限，不要假装数据完整。
- **方案输出纪律（R4）**：给方案必须写清「最终目的」与「分阶段步骤」（每步可观测、可回退）；禁止把"立刻断联 / 冷处理"当解法；所有动作须按对方已确认性格特征定制，禁止通用模板；可对手段分层，但禁止在开头就给极左（断联）或极右（高频加码 / 压迫推进）速决手段。
- **引文硬要求**：每一句引文必须写成「她·日期：原文」或「你·日期：原文」，禁止无主语的裸引文；归因时说明这句话是谁说的、说给谁、说的是谁（她讲前夫 ≠ 她对你的态度）。
- **心态回指**：差评/好评每条须回指心态波段标签（当时她的心态＝发话前瞬时态，非全天均值），异动每个维度须回指其活跃期心态整体偏向。
- **性格滤镜**：四层方法分析法（六~九）的每个应对/处置/整改/可用时机，均须注明针对对方哪条性格优点（入口）或雷区（规避）。
