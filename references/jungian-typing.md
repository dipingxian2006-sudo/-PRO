## 一、四个功能 × 两种态度 = 八维

| | 内倾（I，指向主体） | 外倾（E，指向客体） |
|---|---|---|
| **判断功能**（理性） | **Ti** 内倾思维 | **Te** 外倾思维 |
| | **Fi** 内倾情感 | **Fe** 外倾情感 |
| **感知功能**（非理性） | **Si** 内倾感觉 | **Se** 外倾感觉 |
| | **Ni** 内倾直觉 | **Ne** 外倾直觉 |

| 功能 | 核心追问 | 语言与行为特征 |
|---|---|---|
| **Ti** | 这在逻辑上说得通吗 | 长句、追问定义、纠正用词、先想后回 |
| **Te** | 这能达成什么结果 | 短句、行动导向、时间与数字明确、主动收束 |
| **Fi** | 这对我是否真实/重要 | 表达个人感受与边界、低频但深度高、抗拒被说服 |
| **Fe** | 这对我们意味着什么 | 关心式提问、回应率高、维护氛围、正向词密集 |
| **Si** | 以前是什么样 | 引用共同记忆、细节准确、偏好惯例与稳定 |
| **Se** | 眼前正在发生什么 | 图片/语音多、即时话题、短句、行动邀约 |
| **Ni** | 这最终会走向哪 | 总结性发言、预见性表述、长线判断、爱下结论 |
| **Ne** | 还可能是什么 | 话题跳转快、联想多、抛新选项、不爱收束 |

## 二、功能栈

**主导 → 辅助 → 第三 → 劣势（inferior）**，构成规则：

1. 主导与辅助必须**一感知一判断**，且**一内倾一外倾**
2. 第三与辅助**同功能异态度**；劣势与主导**同功能异态度**
3. 例：INTJ = Ni–Te–Fi–Se

| 类型 | 功能栈 | 类型 | 功能栈 |
|---|---|---|---|
| INTJ | Ni Te Fi Se | ENTJ | Te Ni Se Fi |
| INFJ | Ni Fe Ti Se | ENFJ | Fe Ni Se Ti |
| INTP | Ti Ne Si Fe | ENTP | Ne Ti Fe Si |
| INFP | Fi Ne Si Te | ENFP | Ne Fi Te Si |
| ISTJ | Si Te Fi Ne | ESTJ | Te Si Ne Fi |
| ISFJ | Si Fe Ti Ne | ESFJ | Fe Si Ne Ti |
| ISTP | Ti Se Ni Fe | ESTP | Se Ti Fe Ni |
| ISFP | Fi Se Ni Te | ESFP | Se Fi Te Ni |

## 三、从聊天指标推断八维（与数据层的接口）

### 态度轴：I / E

**不要看话多话少。** 用 `initiated_sessions` 与 `response_rate` 的对照：

| 组合 | 倾向 |
|---|---|
| 发起高 + 接住高 | 外倾（E） |
| 发起低 + 接住高 | 内倾（I）—— 常见于「愿意接但不主动」 |
| 发起高 + 接住低 | 不是 I/E 信号，是**选择性投入**（见 persona-engine） |
| 发起低 + 接住低 | 抽离，类型推断不可靠 |

### 判断轴：J / P

看是否**主动收束**：把话题推向结论、确认时间地点、给明确答复 → J 倾向；
保持开放、留选项、频繁改口 → P 倾向。对应指标：`hedge_hits` 高 → P；计划确认类消息占比高 → J。

### 功能判据

| 功能 | 指标倾向 | 聊天里的样子 |
|---|---|---|
| Te | 句长短、行动导向、`question_ratio` 低 | 「定了」「几点」「我来安排」 |
| Ti | `char_avg` 高、追问定义、延迟较长（想完再回） | 「严格来说」「这个说法不成立」 |
| Fe | `positive_hits` 高、`response_rate` 高、关心式提问 | 「你还好吗」「别太累了」 |
| Fi | 低频但 `char_p90` 高、表达边界 | 「我不太舒服」「我觉得这样不对」 |
| Se | `media_count` 高、即时话题、短句 | 「走啊」「这家好吃」配图 |
| Si | 引用共同记忆、细节准确、偏好惯例 | 「上次那家」「还是老样子」 |
| Ni | 总结性发言、长线判断、爱下结论 | 「迟早会」「本质上是」 |
| Ne | 话题跳转快、抛新选项、`hedge_hits` 高 | 「要不…」「说不定」「还有个思路」 |

**判据要求**：每个功能的判定至少 2 条独立证据（一条指标 + 一条原文）。只有一条 → 标「弱证据」。

## 四、Grip：劣势功能接管

压力、疲惫或长期压抑下，劣势功能会失控接管。这在关系分析里**极其有用**——对方「突然变了个人」的时刻，往往就是 grip，而不是态度变了。

| 主导 | 劣势 | Grip 表现（聊天中可见） |
|---|---|---|
| Ni | Se | 突然沉迷细节、冲动消费、爆发式发图、过度关注身体 |
| Ne | Si | 反复纠结旧事、固执于琐碎细节、翻旧账 |
| Te | Fi | 突然情绪化、「没人理解我」、价值感动摇 |
| Ti | Fe | 突然在意别人怎么看、情绪外泄、渴望被认可 |
| Fe | Ti | 突然冷酷、挑逻辑毛病、疏离切断 |
| Fi | Te | 突然强硬控制、列清单式指责、要求效率 |
| Se | Ni | 突然灾难化想象、认定最坏结果、宿命论 |
| Si | Ne | 突然冒出大量灾难性可能性、疑神疑鬼 |

**识别方法**：找指标突变的窗口（句长骤变、正负比翻转、延迟模式改变），对照上表。

## 五、原型栈（Beebe）

主导/辅助/第三/劣势分别对应四个原型，常用的是前四个：

| 层级 | 原型 | 关系中的含义 |
|---|---|---|
| 主导 | Hero（英雄） | 最自信的部分，也是对方最先看到的面 |
| 辅助 | Parent（父母） | 照顾他人的方式，也是施加压力的方式 |
| 第三 | Child（孩童） | 放松、玩耍、脆弱处——**最容易被安抚的入口** |
| 劣势 | Anima/Animus（灵魂） | 最深盲点，也是**吸引力来源** |

Jung 的观察：人容易被「对方主导功能恰好是自己劣势功能」的人吸引——初期因为互补而着迷，后期因同一差异而冲突。这条可以直接用于解释「刚开始很好，后来总为同一件事吵」。

## 七、大五交叉验证（可选）

荣格/MBTI 的学术支持弱于大五（OCEAN）。做性格分析时**用大五交叉验证**能让结论稳得多：

| 维度 | 聊天指标 |
|---|---|
| 开放性 Openness | 话题多样性、Ne/抽象表述比例 |
| 尽责性 Conscientiousness | 确认计划的比例、守时表述、`hedge_hits` 反向 |
| 外倾性 Extraversion | 发起占比、`peak_hours` 跨度、正向词密度 |
| 宜人性 Agreeableness | 正负比、妥协表述、接住对方话题的比例 |
| 神经质 Neuroticism | 负向词占比、情绪波动幅度、延迟方差 |

两个模型结论一致时置信度上调；冲突时如实列出分歧，不要强行统一。

## 八、可靠性声明（必须写进报告）

这些不是「免责声明」，是准确性事实：

- **重测稳定性差**：MBTI 研究中约半数人五周后测出不同类型。
- **文本自动分型有上限**：公开实现在四分类任务上约 70% 准确率，且训练语料是**论坛长文**（每人约 50 帖），远长于私聊语料。私聊的可靠性只会更低。
- **Jung 本人称类型为「虚构」（Fiktionen）**：是理解工具，不是存在事实。他反对把类型当身份标签。
- **结论一律按假设输出**，并附验证方法。例：「下次抛一个开放式新话题，观察对方是发散联想（Ne）还是收敛下结论（Ni）」。
- 因此荣格分析在本引擎中的定位是**生成可验证的假设与沟通策略**，不是给人贴类型标签。
