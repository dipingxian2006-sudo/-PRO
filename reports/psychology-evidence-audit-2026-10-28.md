# 关系智能 Skill 社会心理学证据审计

日期：2026-10-28

## 结论

三本资料最有价值的共同结论不是“找到更强的话术”，而是建立四道判断纪律：

1. 同时检查个人与情境，不从一次行为直接推人格或爱意。
2. 将口头态度、真实选择和后续兑现分开。
3. 把互惠、一致性、社会认同、喜好、权威和稀缺视为可能影响顺从的机制，不视为喜欢、兼容或承诺的证明。
4. 经典实验用于提出候选解释和核验问题，不能直接预测具体对象。

这些内容已写入新的 `references/social-psychology-evidence.md`，并路由到 `SKILL.md`。同时修正了旧参考中的过度量化和确定性语言。

## 一、三本资料分别提供的证据

### 1. 《改变心理学的40项研究》

核查范围：PDF 页 11–22 的前言、研究体例、伦理与目录；PDF 页 269、409、419、426、437 的高相关研究开篇。

可迁移内容：

- 前言明确承认经典研究可能被后续研究证伪或质疑；每项研究应同时看方法、结果、后续支持/反对和批评。这支持 Skill 的“模型不是事实”纪律。
- 研究伦理部分强调知情同意、自由退出、避免伤害和保密。关系建议对应为当前同意可撤回、拒绝不应被绕过。
- 认知失调研究说明，人可能为既有行为寻找一致性；它适合识别自我合理化和沉没成本，不支持“让对方多投入就会更爱”。
- 态度—行为研究提醒，假设性回答和口头态度未必预测真实情境行为。因此报告必须分开记录表达、选择和兑现。
- 从众、旁观者和服从研究说明群体一致、不确定性、责任分散和权威会影响行为。它们适合检查第三方压力，不支持把顺从解释成真实意愿。

不直接采用：经典研究中的具体比例、单一实验情境和历史样本，不迁移成对当前对象的概率。

### 2. 《影响力》

核查范围：PDF 页 9–16 的序言、六类机制和尾声；PDF 页 48、94、164、228、282、318 的各章开篇。

可迁移内容：

- 互惠：收到好处可能产生回报压力。关系中要区分自然照顾与隐性债务。
- 承诺与一致：既有选择可能增加后续自我辩护。过去的一次同意不能替代当前同意。
- 社会认同：不确定时，人会参考他人行为。朋友圈、闺蜜和“别人都这样”不是双方关系事实。
- 喜好：亲近、相似或赞美可能提高请求接受度，但喜欢不等于同意。
- 权威：头衔和专家身份可能降低审查，心理标签不能压过当事人的自主选择。
- 稀缺：怕失去可能提高主观价值和仓促感，但不提高真实兼容性；禁止虚构忙碌、异性竞争或倒计时。

关键限制：本书研究的是顺从和影响，不能把“更容易答应”改写成“更喜欢你”。书中编辑序言和营销案例存在绝对化表达，不作为规则依据。

### 3. 《自我·群体·社会》

核查范围：PDF 页 8–18 的理论路线和目录；PDF 页 74、129、158、183、205 的社会认知、态度、社会影响、友谊和爱情章节。

可迁移内容：

- 社会行为同时受目标、个人与情境交互影响；文化、认知和社会规范会改变解释。
- 注意、解释、判断和记忆会受期待、自我保护、情绪和既有立场影响。关系分析需要主动搜索反例。
- 强态度可能更稳定，但态度强度和行为仍需具体情境验证。
- 群体一致可能同时产生信息性影响和社会认可压力；公开顺从不能自动视为私下认同。
- 友谊研究重视真实情境中的反复记录、互相回应、自我披露和支持，而不是只靠事后总印象。
- 爱情章节将亲密、激情、承诺作为组织现象的维度，并明确统计工具不能给出个体爱情的全部真相。这支持删除 0–100 爱意式评分。

## 二、对现有 Skill 的审计结果

### 已纠正

| 旧问题 | 风险 | 修正 |
|---|---|---|
| Sternberg 三维 0–100 打分 | 把未校准分数伪装成爱意测量 | 改为“证据充分 / 混合 / 有限 / 未观察到”并附反例 |
| Gottman `5:1` 固定健康阈值 | 将研究场景的比例机械套到私聊 | 只报告观察窗口、候选数量、严重度、修复和变化 |
| 情感投标 `70%/40%` 阈值 | 用样本内比例宣判健康或枯竭 | 比例仅作描述，不单独预测关系走向 |
| “蔑视是最强预测因子，一次即标红” | 忽略对象、语境、严重度和修复 | 改为逐条核对象；反复、直接且无修复时高关注 |
| 千分比自动排除蔑视 | 低频严重羞辱可能被漏掉 | 删除固定阈值，按内容、影响与修复判断 |
| “追逃后永远先减速” | 把单次延迟误当稳定循环 | 要求跨情境序列；减速定义为停止加压并择机协商 |
| Jev “胜出概率” | 排序分数被误读为现实概率 | 改为相对排序，不显示伪概率 |
| 固定 7 天方案与赞美/批评配比 | 机械执行可能制造节奏和交易感 | 改为按事件确定观察窗口，不设通用次数和比例 |

### 保留并强化

- A/B 双轨输出和逐句双轨。
- 事实、解释、建议分层。
- 高唤醒行为不等于爱意。
- 明确拒绝、当前同意、隐私和自主权优先。
- “轻触—响应—收束”用于停止单向消耗，不用于制造焦虑。
- 邀约、关系确认和推进依赖可观察互惠，不依赖固定天数。

### 明确不采纳

- 计划性冷热、让对方猜、间歇性强化。
- 展示异性竞争、制造嫉妒或虚假稀缺。
- “女人都慕强”“需要被征服”等性别本质论。
- 通过小承诺、礼物或沉没成本逐步锁定对方。
- 把吃醋、试探、退缩、脆弱或情绪波动写成真爱证明。

原因不是这些做法“绝对不会短期影响行为”，而是三本资料恰好说明它们可能提高顺从、焦虑或一致性压力；这与真实意愿、长期兼容和可撤回同意不是同一结果。
